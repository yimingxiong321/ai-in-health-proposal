# AI in Health — Course Proposal

One-page project proposal, written as LaTeX (`main.tex`) so it can be compiled on
Overleaf.

## Linking this repo to Overleaf

Overleaf's GitHub sync is a Premium feature. Steps (done from your own Overleaf
account — Claude cannot do this part for you):

1. On Overleaf, go to **Account Settings → Integrations** and connect your GitHub
   account (or sign in to Overleaf with GitHub directly).
2. Click **New Project → Import from GitHub**, and choose `yimingxiong321/ai-in-health-proposal`.
3. Overleaf will create a linked project that pulls `main.tex` from this repo. Use
   Overleaf's "GitHub" menu inside the project to push/pull further edits in either
   direction.

If your Overleaf plan doesn't include GitHub sync, you can instead just upload
`main.tex` directly to a new blank Overleaf project (Upload → select file), and
copy changes back into this repo manually.
